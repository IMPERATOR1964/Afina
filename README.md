# Afina ❤

Маленький сайт для любимой — опросник про наши отношения и галерея совместных фото.

## Как открыть

Просто открой `index.html` в браузере (двойной клик) или запусти live-server в редакторе.

## Как добавить свои фото

1. Положи фото в папку `images/`
2. Назови их так, как указано в `index.html`:
   - **Боковые фото:** `photo1.jpg`, `photo2.jpg` ... `photo6.jpg`
   - **Галерея:** `g1.jpg`, `g2.jpg` ... `g6.jpg`
3. Обнови страницу — фото подтянутся автоматически

## Как изменить вопросы

Открой `index.html`, найди блоки `<div class="question">` — там можно править текст вопросов и варианты ответов.

## Как изменить финальное сообщение

В `index.html` найди блок `<div id="final">` — там надпись "Вместе уже год ❤" и подпись внизу.
